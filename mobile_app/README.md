# Ogrenci Video Ogrenme Asistani

Flutter mobil uygulama iskeleti.

## API URL

Android emulator icin varsayilan backend URL:

```bash
http://10.0.2.2:8000
```

Fiziksel telefon icin uygulamayi su sekilde calistir:

```bash
flutter run --dart-define=API_BASE_URL=http://BILGISAYAR_IP_ADRESI:8000
```
